Northwestern Formula Racing 2027:
(E)Education Board

The (E)Education Board is a training board for new members of Northwestern Formula Racing's DAQ subteam. Benson Zhang and I are designing it so that building and programming it teaches the basics behind most of the boards on our car.

Altium Designer Schematic Design PCB Layout STM32 CAN Bus Soldering

1. Overview

The Project

Most new members join DAQ without having built a circuit board before. The (E)Education Board gives them a real one to learn on. It's a small version of the kind of sensor board we put on the car: a microcontroller, a sensor, and a connection to the car's CAN network.

Because it follows the same layout as our other boards, it also works as a starting template when the team designs new sensor boards.

2. What It Teaches

Learning by Building

  • Soldering small surface-mount parts
  • Powering up a board one step at a time and checking each voltage
  • Sending and receiving messages over CAN
  • Reading a sensor and turning it into useful data
  • Programming and debugging the microcontroller
  • Going from a schematic to a board layout in Altium

We're also putting together the onboarding lessons that go along with the board.

3. Hardware

Board Features

Each section of the board is outlined and labeled, so it's easy to tell what every part does.

SubsystemDetails
MicrocontrollerSTM32 with an external crystal, plus reset and boot buttons
SensorForce sensor read through an external ADC
CANSame kind of connection our car's boards use to talk to each other
PowerRuns from the car's 12V supply or USB-C, with protection against plugging power in backwards
Voltage Conversion12V down to 5V, then 5V down to 3.3V
ProgrammingSWD header for flashing and debugging firmware
Testing ZoneLEDs and test points for the 12V, 5V, and 3.3V rails, so members can check each one during bring-up
